# Security Policy

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub:
[open a draft security advisory](https://github.com/ionos-cloud/cluster-api-provider-proxmox/security/advisories/new).
Do not open a public issue for a vulnerability.

Please include all the information that will help us triage and prioritise your report.
We aim to acknowledge a report within 5 working days.

## Fixing vulnerabilities

We welcome fixes to reported issues.
Please propose them in the private advisory's temporary fork,
or send patches directly to one of the security contacts.
